# ShopHUB — İndir

E-ticaret komuta merkezi: Trendyol ürün araştırması, Shopify mağaza kurulumu, Meta reklam analizi ve kârlılık takibi.

## ⬇️ İndirme

**[En son sürümü indir →](../../releases/latest)**

| Bilgisayar | Dosya |
|---|---|
| Windows 10 / 11 | [ShopHUB-Windows-Kurulum.exe](https://github.com/mertkurtul16/shophub-indir/releases/latest/download/ShopHUB-Windows-Kurulum.exe) |
| Mac — Apple M1 / M2 / M3 / M4 | [ShopHUB-Mac-AppleSilicon.dmg](https://github.com/mertkurtul16/shophub-indir/releases/latest/download/ShopHUB-Mac-AppleSilicon.dmg) |
| Mac — Intel işlemci | [ShopHUB-Mac-Intel.dmg](https://github.com/mertkurtul16/shophub-indir/releases/latest/download/ShopHUB-Mac-Intel.dmg) |

Mac'inin hangisi olduğunu öğrenmek için:  → **Bu Mac Hakkında**. "Apple M…" yazıyorsa Apple Silicon, "Intel" yazıyorsa Intel dosyasını indir.

## Windows kurulumu

1. `ShopHUB-Windows-Kurulum.exe` dosyasını çalıştır.
2. "Windows kişisel bilgisayarınızı korudu" uyarısı çıkarsa: **Ek bilgi** → **Yine de çalıştır**.
3. Kurulum bitince ShopHUB açılır ve kurulum sihirbazı eksik programları kendisi kurar.

## Mac kurulumu

1. DMG dosyasına çift tıkla, **ShopHUB**'ı **Uygulamalar** klasörüne sürükle.
2. Uygulamalar'dan ShopHUB'ı aç. Uyarı çıkınca **Bitti**'ye bas.
3.  → **Sistem Ayarları** → **Gizlilik ve Güvenlik** → en altta **Yine de Aç** → şifreni gir.
   (Bu adım yalnızca ilk açılışta gerekir.)
4. Tarayıcıda kurulum sihirbazı açılır; **Eksikleri kur**'a bas. Apple "Komut satırı geliştirici araçları" penceresini açarsa **Yükle**'ye bas.
5. ShopHUB, ekranın üstündeki menü çubuğunda simge olarak çalışır.

## Verileriniz

Tüm veriler yalnızca sizin bilgisayarınızda saklanır; ShopHUB hiçbir veriyi dışarı göndermez.
Uygulamayı kaldırmak verilerinizi silmez.
